# Analytics

## Goals
- Provide operational insights using Supabase data and external analytics.

## Core Metrics
- Sales: total revenue, AOV, orders count.
- Product performance: top sellers, low stock.
- Customer metrics: repeat rate, LTV (from orders).
- Content metrics: article count, publish cadence.

## Data Sources
- Orders and line items for sales.
- Inventory levels for stock health.
- External analytics (optional) for traffic and conversion.
