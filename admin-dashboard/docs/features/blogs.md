# Blogs and Articles

## Goals
- Manage blogs and articles with scheduling and SEO controls.

## Data Tables
- `blogs`, `articles`.

## Blog Management
- Create/edit blogs (title, handle, tags).

## Article Management
- WYSIWYG editor for `body_html` with image embeds.
- Summary field for listing pages.
- Publish now or schedule using `published_at`.

## Media
- Upload article images to Supabase Storage, set `supabase_image_url`.

## SEO
- Handle, title, summary, tags.
