# Discounts

## Goals
- Create and manage Shopify-style price rules and discount codes.

## Data Tables
- `price_rules`, `discount_codes`, `discount_applications`, `order_discount_codes`.

## Discount Types
- Percentage, fixed amount, shipping discounts.
- Applies to products, collections, or entire order.

## Scheduling
- Start/end dates with validation against overlapping rules.

## Usage Controls
- Once per customer, usage limits, allocation methods.

## Reporting
- Show usage count and affected orders.
