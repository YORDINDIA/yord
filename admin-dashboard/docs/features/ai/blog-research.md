# AI: Blog Research and Drafting

## Scope
Create new articles using external research and internal product links.

## Workflow
1. Admin enters topic + keywords.
2. Research step gathers sources and citations.
3. Draft includes summary, outline, and full HTML.
4. Admin reviews and edits.
5. Publish with tags and schedule.

## Requirements
- Store citations with the draft for traceability.
- Avoid direct copying; summarize and attribute.
- No publish without human approval.
