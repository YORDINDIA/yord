# Open Questions (Answered)

All questions below have current decisions; revisit if scope changes.

## Product and Catalog
- Are there additional product-level fields or metafields needed for YORD-specific merchandising? Not currently.
- Should product handles be user-editable after publish? Yes, admin can edit product handles.

## Orders
- Which fulfillment carriers or tracking formats are required? No integration required for now.
- Do refunds need to trigger external payment gateways? Yes, admin can trigger refunds.

## AI
- Which AI provider(s) will be used for text and image generation? OpenAI.
- What approval thresholds or review roles are required? Admin can approve or reject generated content.

## Roles
- Exact role mapping and which team members need access in phase 1? Only Admin role for now.
